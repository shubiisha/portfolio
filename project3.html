Project overview

This project focuses on a full customer-facing experience: browsing product listings, adding items to a cart, checking out with input validation, and managing persistent order-related data through a backend API.

Key functionality

  • Product catalog browsing
  • Cart quantity controls
  • Checkout and order flow
  • Order and customer data handling
  • Admin-style product management flow
Technology stack

Built around a modern full-stack structure

Frontend

React UI for shopping, cart interaction, and storefront presentation.

Backend

Express API for managing product and order data with request handling.

Database

MySQL for structured relational storage and real product/transaction data handling.

Auth

Firebase-based authentication to support secure user access flows.
