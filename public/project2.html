Key Features of the E-Commerce Platform

Designed with a modern customer storefront and back-office management system backed by relational data persistence.

🔐

Secure Authentication

Users can securely create accounts, log in, and maintain authenticated sessions using Firebase.

  • User Registration & Login
  • Token Verification
  • Protected Customer Routes
  • Secure Logout Flow
🛍️

Product Browsing

Browse dynamic product listings with rich image previews, pricing, and item specifications.

  • Dynamic Product Grid
  • Detailed Product View
  • Live Stock Indicators
  • Categorized Presentation
🛒

Dynamic Shopping Cart

Add, increment, decrement, and remove items with instant cart subtotal and tax calculation.

  • Real-time Quantity Controls
  • Instant Price Subtotaling
  • Dynamic Badge Count
  • Persistent Cart State

Streamlined Checkout

Review order items, fill in shipping information, and place orders through a verified checkout page.

  • Itemized Order Summary
  • Client-side Form Validation
  • Address & Contact Capture
  • Instant Confirmation Screen

Order History

Customers can review their past purchases, order statuses, timestamps, and receipt details.

  • Past Orders Dashboard
  • Order Date & Reference ID
  • Purchased Items Breakdown
  • Customer-specific Records

Admin Dashboard

Administrative interface to oversee store operations, add new products, and track customer orders.

  • Add & Edit Products
  • Delete Outdated Listings
  • Review Customer Orders
  • Product Inventory Overview

RESTful Backend API

Node.js and Express server with structured REST endpoints managing CRUD operations for store data.

  • Order Placement APIs

  • JSON Payload Handlers

Relational Database

Structured relational MySQL tables ensuring referential integrity across users, products, and orders.
