Blog Platform with Comments

A modern full-stack blogging platform where writers can register, compose, publish, and manage their own articles, while readers can interact through nested post comments. Built with a React frontend, Express REST API backend, and relational MySQL database.

Express Backend

Node.js & Express API server handling requests, sanitizing inputs, and executing SQL operations.
